# SaaS-Subscription-Churn-Analysis-

# 🎯 Overview
This project focuses on analyzing customer churn, support performance, and feature usage for a fictional SaaS business scenario called RavenStack.The dashboard was developed using Microsoft Excel to explore business performance, identify patterns, and generate actionable insights.

# ❓Business Problem
- How many accounts have churned?
- How do churn rates vary across industries and initial plan tiers?
- What are the most frequently recorded churn reasons?
- How do churn events change over time?
- Which product features receive the highest usage?
- How does customer support response time vary by ticket priority?

# 🗂️ Dataset
The synthetic dataset contains five interconnected tables:
- Accounts 
- Subscriptions 
- Feature Usage 
- Support Tickets 
- Churn Events 

**Dataset Source:** https://www.kaggle.com/datasets/rivalytics/saas-subscription-and-churn-analytics-dataset

# 🛠️Tools & Technologies
- Microsoft Excel
- Power Query – Data transformation
- Power Pivot – Data modelling and relationships
- DAX – measure calculations
-	PivotTables & PivotCharts – Data analysis and visualization
-	Slicers – Interactive filtering

# 📌 Key Metrics:
👥 Total Accounts: 500
🔄 Churned Accounts: 110
📉 Account Churn Rate: 22%
📋 Total Subscriptions: 5,000
⛔ Churned Subscriptions: 486
📊  Subscription Churn Rate: 9.72%

# 💡 Key Findings
-	22% of accounts were marked as churned at some point.
-	9.72% of subscriptions were marked as ended.
-	Monthly churn events peaked in Dec 2024, indicating a period with increased churn activity.
-	Feature_32 recorded the highest usage, highlighting its popularity among users.
-	High Priority tickets had the highest average first response time, highlighting an area for service improvement.

# 🚀Recommendations
-	Review High-Churn Segments to improve customer retention.
-	Address Pricing Concerns to reduce pricing-related cancellations.
-	Improve Support Response to increase customer satisfaction.
-	Promote Feature Adoption to boost feature engagement.
